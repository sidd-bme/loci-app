Inspect saved studies from the command line

Query measured objects in a saved .loci-study from any terminal. Against the 38-cell colony result above, the first command finds 19 cells matching area (µm²) and spacing (µm) bounds. The second locates label 4 at zero-based row Y=91, column X=346.

loci objects --project colony.loci-study --area 120:350 --spacing 10:40 --limit 3
loci locate 4 --project colony.loci-study

What travels with a result

A saved study records the source, geometry, method, measurements and review decision. Reopen the study to inspect how a particular result was produced.

Immutable sources and explicit axes

Original TIFF, OME-TIFF, IMS, OME-Zarr, SVS, NDPI, NIfTI, NRRD, and DICOM inputs remain untouched on disk. Axes (C, Z, Y, X, T), physical calibration, pyramid levels, and registration transforms stay attached to the data. Display contrast and pseudocolor never alter raw intensity quantification. Capability matrix · Quantification · Registration

Spatial measurements and batch recipes

Draw source-bound ROIs, quantify puncta and channel intensity, or measure cell density in distance bands along a tissue boundary. Chain ordered preprocessing, segmentation, and measurement steps in the Workflow builder, preview on a crop, and repeat saved recipes across compatible study images locally or on an explicitly configured remote compute profile. Spatial bands · Visual workflows · Remote compute

Revisions and export integrity

Manual label edits create a new revision while retaining the original mask and measurements for audit. Review the exact revision you intend to share and publish atomic bundles containing OME-TIFF labels, CSV tables, geometry, settings, and review history, with Python and R readers for scientific data packages. Model identity and assistant permissions

For supported local models, Loci checks package hashes and runtime compatibility and shows the publisher’s terms. A researcher chooses which images, regions, channels and operations an assistant may use. Saving an assistant’s model prediction requires approval of the inspected preview. Install the Apple silicon beta

The published binary is v0.2.0-beta.2 for Apple silicon macOS, distributed as an ad-hoc-signed, unnotarized prerelease with SHA-256 checksums. Verify the ZIP archive, unzip it, and move Loci.app to Applications. If macOS blocks the first launch, follow the Privacy & Security steps in the installation guide.
