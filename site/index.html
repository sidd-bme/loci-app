Work with a research assistant

Give Codex or Antigravity access to a selected part of a study. An assistant can inspect images, run permitted analyses and return results for review in Loci.

  1. Ask an assistant to find cells using the membrane channel.
  2. Choose the image, region, model and measurement channel to share.
  3. Loci runs Cellpose locally.
  4. The workbench retains the exact preview for inspection.
  5. Inspect the overlay and approve the exact prediction.
  6. Save the mask with its raw per-cell actin measurements.

Loci runs its Model Context Protocol (MCP) server on your computer. Your assistant and its provider can receive the content you authorize.

Where Loci fits

Labs often use several imaging tools. The choice depends on the data, the analysis, and how the next person will repeat it.

SoftwareTypical workRepeating or extending it
LociLocal studies linking images, object measurements, model previews and reviewed exports.Visual recipes, the Loci CLI, and study-scoped MCP for assistants.
ImarisCommercial 3D and 4D microscopy visualization, surfaces, spots and tracking.Tracking, batch processing and extensions depend on the package and modules.
napariInteractive multidimensional viewing with image, label, point and shape layers.Drive the viewer from Python, a notebook or a plugin.
QuPathWhole-slide tissue annotation, cell detection and object classification.Run Groovy scripts across projects and export annotations and measurements.
Fiji / ImageJGeneral microscopy processing, regions of interest and particle measurements.Record ImageJ macros, write scripts and run plugins in batch.
