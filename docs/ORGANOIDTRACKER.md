# Inspect OrganoidTracker 2.0 tracks

Open the matching 3D OME-TIFF time series and choose **Analyze → Track over time → OrganoidTracker lineage**. Enter the OrganoidTracker time point corresponding to the first image frame. Confirm the image and declare the origin of the graph, then select the local `.aut` file. The upstream graph has no image fingerprint. The user supplies the correspondence and Loci checks compatible calibration, frame range and coordinate bounds. It binds the imported record to the study source ID, source SHA-256 and series number and retains the SHA-256 of the selected file.

The inspector reads the explicit `version: "v1"` D3 node-link format distributed with the OrganoidTracker 2.0 paper. Each identity is the upstream time point and fractional XYZ pixel position. Edges connect consecutive frames in time order. Two outgoing edges from the same position appear in the parent–daughter filter. A branch is a claim in the external graph. The inspector also displays imported link probability and context-aware marginal probability independently, including missing values. The origin declaration applies to the whole file. Probability fields alone cannot identify which model generated a graph or which individual links a curator edited. [Official versioned reader](https://github.com/jvzonlab/OrganoidTracker/blob/07a379a1c485f717548a906d2141b97e03fde3c1/organoid_tracker/imaging/io.py) · [Betjes et al., Fig. 1 and Fig. 3](https://doi.org/10.1038/s41592-025-02845-6)

Choose either endpoint to center the native viewer and mark its XY location on the nearest source Z section. Position readouts preserve fractional Z. Physical coordinates use a local image origin with diagonal XYZ spacing in µm. Elapsed seconds start at the first source frame. Save the study and choose **Inspect saved graph** to revisit an immutable import. The dropdown lists the latest 100 graph records for the selected source.

## Supported inputs

The graph requires a declared XYZ calibration and time interval in minutes. Loci compares them with the source ZYX calibration and OME time increment in seconds. This reader accepts an unshifted image grid, at most 50,000 positions and 50,000 links, and a file up to 16 MiB. It rejects v2 tracklets, time gaps, merges, multiway branches, offset images, variable timing, stage transforms, missing endpoints and conflicting position lists. The study graph stores explicit positions, links and their two probability fields. Other upstream metadata such as penalties and display colors stays in the original file.

## Publisher example

Betjes et al. deposited the sample movie and automated tracking results under CC BY 4.0. The headless check used the original **Marginalized positions.aut** from Zenodo record 13982844, SHA-256 `6147a70cb0e7b6783253f936dbcdddd2ac7f3e48a211e38c39b27fc224793278`. The archive matched the publisher's MD5 `a57f0b5725e4304a52857b62e92da7cb`. The original ImageJ movie has 51 frames × 30 sections × 512 × 512 pixels. For this check a separate OME-TIFF carried the graph's 0.32 × 0.32 × 2 µm spacing and 720 s interval. All 401,080,320 uint16 samples matched the original. The calibration check in this example therefore exercises unit and axis handling using a common upstream declaration. [Publisher example and licence](https://zenodo.org/records/13982844)

After Save As and reopen, the native graph matched all 6,802 upstream position tuples and all 6,665 edges with their reported probabilities. There were 48 two-daughter parents, 81 marginal probabilities below 0.99 and 20 edges without a link probability. Five native 7 × 7 source crops matched the original movie at a parent, its two daughters and both endpoints of the lowest-marginal-probability link. This checks import and readback fidelity. The example supplies automated tracks and does not establish the biological correctness of those divisions.

## Assistant inspection

Under **Graph identity**, Loci shows the exact source ID and fingerprint, graph ID and full content SHA-256 needed by the read-only `organoidtracker_links` inspection action. Grant the action on the entire native source with granted-source result access. The file omits the generating channels and the neighborhood used for each marginalized score, so a cropped, channel-limited or plane-limited grant cannot cover its evidence.

Use `inspect_action` with that binding, a filter of `all`, `branch` or `low-marginal`, a zero-based offset and a page limit of 1–100. For `low-marginal` specify the exclusive `marginal_below` cutoff. Optional `source_t` selects links starting at that source frame. Rows preserve missing scores, both endpoint identities, XYZ coordinates in pixels and image-local µm, upstream time points and elapsed seconds. Edge and node indices are stable within the pinned graph.
