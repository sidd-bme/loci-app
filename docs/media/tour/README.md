# Images in the workbench tour

The [project README](../../../README.md) shows the running Apple silicon development app. The volume and MRI views were captured on 28 November 2026 with build 78. The assistant connection and Cellpose preview were captured with build 78 on 27 November. The remaining views show build 77 on 27 November. The interface uses Loci’s native Graphite and Black themes. The images were cropped or resized for reading on GitHub. The CLI capture uses the packaged command against a saved local study. The [public binary](../../RELEASE_STATUS.md) has its own release and feature history.

## Fluorescence and cell measurements

- [Human iPS cell colony](fluorescence.webp). Thirstrup and the Allen Institute for Cell Science Microscopy & Image Analysis Team, BBBC034v1. The view is a maximum-intensity projection of six consecutive native sections (zero-based Z15–20) in field AICS_12_134. Plasma membrane appears in amber, GFP-labelled α-tubulin in aqua and DNA in violet. Source spacing is 0.065 µm in XY and 0.29 µm in Z. Loci set the channel windows and display colours. [BBBC034v1](https://bbbc.broadinstitute.org/BBBC034) · [Cell line](https://cell-catalog.allencell.org/cell-line/aics-12-105/) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- [Object distributions](cell-measurements.webp) and [CLI session](cli-objects.webp). The BBBC034v1 colony-center field is a different acquisition. Its membrane, β-actin and DNA channels were windowed into the RGB input for Cellpose-SAM v2 at native section 40. Loci imported the 38 predicted instance labels on the original scalar grid for measurement. The CLI reads the same field and mask. Area and nearest-centroid spacing are calibrated. The query returns 19 of 38 cells and displays the first three. Label 4 lies at row 91, column 346. The terminal image was captured from xterm.js displaying the packaged program’s actual PTY output. [BBBC034v1 and CC BY 4.0 terms](https://bbbc.broadinstitute.org/BBBC034) · [Cellpose-SAM v2 checkpoint](https://huggingface.co/mouseland/cellpose-sam/blob/7c61431b5fbb078f3296754bd15d9f51b320f837/cpsam_v2)
- [Nuclear disagreement](compare-nuclei.webp). A06, site 6, is one Hoechst image of U2OS cells from BBBC039v1, contributed by Caicedo and colleagues to the Broad Bioimage Benchmark Collection, CC0. At intersection-over-union ≥0.50, 56 object pairs matched between the BioImage.IO nuclei-boundary ONNX result and the threshold/connected-component result. The ring identifies ONNX label 49, which has no matching counterpart at this cutoff. Its area is 851 px² on this uncalibrated field. [BBBC039v1](https://bbbc.broadinstitute.org/BBBC039) · [ONNX publisher](https://doi.org/10.5281/zenodo.6647674)

## Image modes

- [Confocal volume](volume-3d.webp). The Arabidopsis thaliana ovule is wild-type Col-0, stage 2-II, from EM_C_81.ims, deposited by Célia Baroux, Ethel Mendocilla-Sato and Daphné Autran for the study by Hernández-Lagana and colleagues. The volume viewer applies normal shading and a teal display colour to the 256 × 256 × 243 native grid. [Publisher dataset and CC0 terms](https://zenodo.org/records/4433202)
- [Whole-slide tissue](whole-slide.webp). Aperio CMU-1.svs, distributed by the OpenSlide project under CC0. The native slide reader displays a region at level zero. The Navigator thumbnail shows where it lies in the 46,000 × 32,914 pixel slide. [Aperio test data and credits](https://openslide.cs.cmu.edu/download/openslide-testdata/Aperio/)
- [Linked MRI](linked-mri.webp). ICBM152 2009b nonlinear asymmetric T1 population template at 0.5 mm isotropic spacing. Copyright © 1993–2004 Louis Collins, McConnell Brain Imaging Centre, Montreal Neurological Institute, McGill University. The linked anatomical planes and their spatial context use the NIfTI geometry. [Dataset](https://www.mcgill.ca/bic/icbm152-152-nonlinear-atlases-version-2009) · [References and full permission notice](../launch-credits.md#mni-template-references-and-notice)
- [Organoid time series](organoid-lineage.webp). Max Betjes and colleagues’ OrganoidTracker 2.0 example contains a 51-frame movie and an externally calculated lineage graph. Loci imported the published v1 graph and shows its stored link and marginal probabilities. The OME-TIFF retains the publisher’s image values and carries the matching graph calibration. [Data, attribution and CC BY 4.0 terms](https://doi.org/10.5281/zenodo.13982844) · [Method](https://doi.org/10.1038/s41592-025-02845-6)
- [Digital holographic microscopy](phase-microscopy.webp). Paul Müller, Mirjam Schürmann, Salvatore Girardo, Gheorghe Cojoc and Jochen Guck. The scalar source is the published 8-bit cell image distributed in scikit-image. The OME-TIFF preserves all 550 × 660 values and records the 0.107 µm XY spacing. The 13.589 µm line is a user-selected distance. [Original study](https://doi.org/10.1364/OE.26.010729) · [Dataset and CC0 terms](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.cell)
